TOGAF-guided EA assessment POC for Coromandel International. Full spec: `PROJECT_CONTEXT.md` (read it first).

## Non-negotiables
- **Environment:** use the existing conda env `pmo-intel-engine`. Never create a venv or a new conda env. Install Python deps into it with `conda run -n pmo-intel-engine pip install -r backend/requirements.txt` and keep `requirements.txt` current.
- **TOGAF is ground truth.** Every AI output is grounded in retrieved TOGAF chunks and cites them (`TOGAF 9.1 §x.y · p.N`). No uncited TOGAF claims.
- **Numbers come from rules, not the LLM.** Scores, dispositions, gaps, waves and ₹ come only from `backend/app/rules/` (a port of `rules_reference.py`) using parameters in `seed/config.json`. The LLM only writes narrative over computed results.
- **Provenance tracked, not shown.** Every seeded record keeps `source: deck|public|assumed|client` in the data and AI prompts (the AI phrases assumed data as "to validate", never as fact), but the UI shows no source badges or source columns (removed 2026-11-03 at the user's request). Never invent vendor names (use `TBD`).
- **Free Gemini only.** Max 6 AI call types (see PROJECT_CONTEXT §6). All AI calls are cached, rate-limited (8 RPM) and button/panel-triggered, never on page load or in loops. Everything works with **no API key** (deterministic fallback).
- **Eight screens only:** Dashboard, Approach & Plan, Vision & Guardrails, Business Architecture, Applications, Data & Technology, IT Budget, Roadmap & Governance (Approach & Plan and IT Budget added 2026-11-03 at the user's request). Do not add further screens. Phase screens use PhasePlan → StepBar → step card → InsightsCard.

## Commands
Cross-platform (user is likely on Windows / PowerShell). Do not rely on `make` or bash-only syntax.
- Ingest TOGAF: `conda run -n pmo-intel-engine python -m app.rag.ingest` (from `backend/`)
- API: `conda run -n pmo-intel-engine uvicorn app.main:app --reload --port 8000` (from `backend/`)
- Tests: `conda run -n pmo-intel-engine pytest -q` (from `backend/`)
- Web: `npm install && npm run dev` (from `frontend/`; Vite proxies `/api` → `:8000`)
- Golden values: `python rules_reference.py` (repo root)

## Conventions
- **API:** all under `/api`. One `GET /api/{screen}` returns everything a screen needs (inputs + computed). Mutations are `PUT`/`POST` on the narrowest resource. Pydantic response models mirror the TS types in `src/lib/api.ts`.
- **Rules:** pure functions, input dicts in and dicts out, no DB access. Routers load state → call rules → return.
- **RAG:** `retrieve(query, screen, phases, types, k)`. Index files are loaded once at startup. Ingest is idempotent (skip if the PDF hash is unchanged).
- **LLM:** only via `app/llm/gemini.py::generate_json(kind, prompt, schema)`. Prompts live in `prompts.py` with the grounding contract. Excerpts are numbered `[1]..[k]`.
- **Frontend:** TanStack Query per screen. Colours come from `theme.ts` (band → colour). No inline hex elsewhere. Every screen is PageHeader → 4 KpiCards → main visual → table → FindingsCard.
- **Copy:** short, consultant tone, no lorem ipsum, no emojis.
